# M1 — Core rendering + blind test

## Status

Completed 2026-08-13. Local test suite: 34 passed. Blind-test figure set
generated for all 20 molecules x {acs, modern} (40 figures, PNG + SVG).

## Completed

- `styles.py`: `acs` (ACS1996 base + tuning), `modern` (classic CPK
  heteroatom colors: O #FF0D0D, N #3050F8, S #E8C300, Cl #1FB01F),
  `textbook-cn` (pure B/W, ~1.3x ACS bond width, larger labels, stereo wedges
  only). All support a transparent background via `render_molecule`.
- `molecule.py`: SMILES / InChI / molblock auto-detection, sanitize-only
  cleanup, CoordGen 2D layout, SVG + PNG (Cairo) output, auto canvas sizing,
  atom indices, atom highlighting, unassigned-stereo-center warnings, and
  `ChemGlyphParseError` messages that include the raw RDKit error plus a
  quick-fix suggestion.
- `svg_utils.py`: viewBox parsing, group wrapping, composition, text width
  estimation, stroke-width scaling, hex color parsing (stdlib only).
- `validate.py` quick-fix core: the four §7 rules plus the full
  `ValidationReport` (landed early — §5 requires the quick-fix suggestion in
  parse errors).
- `benchmarks/`: the fixed 20-molecule list, `generate_blind_test.py`
  (shuffled numbering, `answer_key.json`), and a generated figure set
  (`answer_key.json` is tracked; figures stay local).
- Golden snapshot tests: 3 styles x 3 molecules with structural assertions
  (element id sets, color presence, stroke widths, stereo wedge segment
  counts) — no pixel comparison.

## Deviations from spec (and why)

1. RDKit 2026 API differences are handled with compatibility shims:
   colors are plain tuples (no `DrawColour`), `setAtomPalette(dict)` replaces
   `atomColourPalette[...]`, `useBWAtomPalette` is a property, and
   `SetACS1996Mode` takes `(options, meanBondLength)`. The shims keep the
   declared `rdkit>=2024.9` floor working.
2. "rdMolStandardize basic cleaning (sanitize only)" is implemented as
   `Chem.SanitizeMol` + stereo/CoordGen setup. `rdMolStandardize.Cleanup`
   was avoided because it performs functional-group normalization and
   uncharging beyond sanitize. TODO(question) below.
3. Auto canvas sizing uses the molecule's 2D coordinate bounding box to pick
   an aspect-matched canvas (square canvases left 50%+ empty for flat chains).
   RDKit still auto-scales the drawing to fit.
4. Molblock input is passed to RDKit untouched: the RDKit 2026 reader is
   sensitive to leading-whitespace stripping (a stripped molblock can fail to
   parse). Round-tripping `MolToMolBlock` output works.
5. PNG via Cairo works in the current `rdkit` PyPI wheel; the failure path
   still raises `ChemGlyphRenderError` with install guidance for bare builds.

  deliberately exclude.
- Should `RenderResult.warnings` also cover unassigned E/Z bond stereo, or

- One borderline auto-sizing case (linalool, a very flat chain) still has a
