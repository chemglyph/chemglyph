## Deviations from spec (and why)

1. PyPI upload was deferred to the maintainer's credential provisioning; it
   was completed on 2026-08-13: v0.1.0 sdist + wheel are live at
   <https://pypi.org/project/chemglyph/0.1.0/> and verified end to end
   (`pip install chemglyph` in a clean venv). TestPyPI was skipped because
   the provided token belongs to pypi.org; an equivalent local-wheel install
   check was used instead (details in REVIEW-1.md).
2. The blind-test comparison panel for ChemDraw is left for manual review
   (spec says ChemDraw figures are made by hand and mixed in by the
   maintainer). The committed comparison image covers ChemGlyph vs stock
   RDKit.
3. The recording GIF for Claude Desktop end-to-end usage is a manual step
   (Claude Desktop is not available in this environment); the server itself
   is exercised over stdio by the M3 integration tests.
4. External submissions:
   - awesome-mcp-servers: PR opened from the alias account —
     https://github.com/punkpeye/awesome-mcp-servers/pull/12063
     (title opts into the repo's automated-agent fast-track with 🤖🤖🤖).
   - Official MCP registry: publishing requires the `mcp-publisher` CLI with
     a registry credential, which is a maintainer-owned secret. Steps are in
     the checklist below.
