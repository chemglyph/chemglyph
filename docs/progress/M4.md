## Deviations from spec (and why)

1. PyPI upload is not performed from this machine: it needs the PyPI
   credential and package-name registration, which §M0 explicitly assigns to
   the maintainer. The artifact is built and verified locally; upload steps
   are in the checklist below.
2. The blind-test comparison panel for ChemDraw is left for manual review
   (spec says ChemDraw figures are made by hand and mixed in by the
   maintainer). The committed comparison image covers ChemGlyph vs stock
   RDKit.
3. The recording GIF for Claude Desktop end-to-end usage is a manual step
   (Claude Desktop is not available in this environment); the server itself
   is exercised over stdio by the M3 integration tests.
4. External PR submissions (MCP registry, awesome-mcp-servers) are prepared
   and attempted separately; their target formats are validated against the
   upstream repos at submission time.
