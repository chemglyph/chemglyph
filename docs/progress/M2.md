## Deviations from spec (and why)

1. Line wrap follows the spec's MVP text literally: the overflowing row ends
   without an arrow, the next row starts with the step's arrow, and the
   intermediates are redrawn once. A true "down arrow" glyph is deferred.
2. Continuation uses set equality of canonical SMILES (order-insensitive).
   The aspirin example's step 2 hydrolyzes aspirin, so its products are not
   exactly step 1's products; the redraw is therefore correct. The no-redraw
   path is covered by a dedicated test (`O → CC → CCC`).
3. `layout.align` is accepted and reserved: MVP always vertically centers
   fragments on the row midline, satisfying §6.2.5 for every row.
4. Condition/yield font size is fixed at 14px rather than derived from the
   style. Arrow length still grows with measured label width per §6.2.2.
