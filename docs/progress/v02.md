# v0.2 — kickoff

Date: 2026-08-14. Covers the user-reported rendering fixes and the v0.2
backlog agreed in REVIEW-1.

## Fixed this cycle

- **ACS labels were tiny.** Root cause: `SetACS1996Mode` was called with a
  constant mean bond length and its preset pins `fixedFontSize = 10`, so
  min/max font caps were ignored and ACS labels rendered ~3x smaller than
  `modern`. Fix: pass the molecule's real `MeanBondLength` and reset
  `fixedFontSize`/`fixedBondLength` to auto. Regression tests now assert both
  the configured values and the rendered glyph height (ACS >= 65% of modern).
  Verified on rdkit 2024.9.4 and 2026.3.5.
- **Gallery/comparison layout.** The README sheets are now a uniform grid:
  every molecule renders on the same square canvas, a molecule-name column,
  a style/renderer header row, and light grid separators
  (`scripts/generate_docs_images.py`, `docs/images/*`).
- **Quality sweep.** Parser-specific error suggestions (InChI/molblock no
  longer receive SMILES fixes), RDKit stderr no longer leaks during
  validation probes, a console-script MCP smoke test, and version stamps
  (`chemglyph_version`, `rdkit_version`) in `answer_key.json`.
- **Blind test runbook.** `benchmarks/RUNBOOK.md` covers panel preparation,
  blinding, grading, scoring (36 eligible pairs, >= 40% pass), and hygiene.
